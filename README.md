# USP17L2 and USP19 in osteoporosis

Code accompanying:

> Mousavi SZ, Payab N, Sina M, Dehghan M, Pourahmad R, Hadizadeh M.  
> Unveiling the role of the USP family in osteoporosis: a focus on USP17L2 and USP19.  
> *Journal of Clinical and Translational Research*. 2026.  
> https://doi.org/10.36922/jctr025370062

## What this repository contains

Bioinformatics analysis of ubiquitin-specific protease (USP) family genes in osteoporosis, focusing on USP17L2 and USP19.

## Status

Analysis scripts will be added to `scripts/`.

## Data policy

Public datasets only. No identifiable patient data.
